# Frontend quality checks
Run from frontend: bash scripts/install-quality.sh. Then npm run format, npm run lint, npm run test:coverage, npm run build, npm run test:e2e, npm run bundle:report, npm run lighthouse. Lighthouse default is mobile; for desktop run npm run lighthouse -- --collect.settings.preset=desktop (copy mobile reports first). Reports are local evidence, not precomputed. Tests use fixture files for client validation only, not ML inference. Axe checks dashboard only; extend to all routes and manually verify keyboard, zoom, contrast, orientation and touch targets. Legacy unused code is excluded from lint and coverage. No coverage threshold is asserted for frontend. Bundle report measures emitted chunks, not dependency attribution. If dependency peer resolution fails, do not force install; share npm error. Add generated report folders to gitignore or archive evidence separately.
